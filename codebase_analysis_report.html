libkm Analysis Report

libkm is a MATLAB toolbox for behavioral and neural data analysis. It is organized as a set of cooperating sublibraries for big-table aggregation, exploratory population statistics, trial-aligned time-series analysis, state-space analysis, and shared utility functions.

Language: MATLAB Type: toolbox Domain: neural and behavioral analysis Style: path-based reusable library

Executive Summary

This repository is a reusable lab toolbox rather than a single project. Its core value is making common analysis workflows faster and more consistent: save per-session results, merge them into one population table, filter and visualize those results, and analyze event-aligned PSTHs across trials, neurons, sessions, and subjects.

The strongest design idea is that loading and population analysis are treated as first-class workflows. Data is loaded broadly first, then filtered later, which makes iterative analysis easier during exploratory science.

Top-Level Structure

libbigtable/

Aggregates per-session result files into a large numeric array or table keyed by unit/session identifiers.

libpopulation/

Population plotting and statistics for column-based data, with many functions integrating visualization and significance testing.

libtimeseries/

PSTH and event-aligned time-course analysis for neural and behavioral signals across trials and groups.

libss/

State-space analysis built on timecourse arrays and PSTH-derived representations.

libutil/

Shared utilities for plotting, axis control, NaN-aware operations, key-value parsing, grouping, and naming.

demo/

End-to-end demo scripts showing how the modules are meant to work together in real analysis workflows.

Main Workflow

1. Save session-level outputs
Per-session analyses write one-line result rows or PSTH structs using conventions expected by the loaders.
2. Build a population table
libbigtable loads many result files into aPD or tPD, keyed by unitname.
3. Filter after loading
Boolean masks and group filters are applied after broad loading, which is the explicit philosophy shown in the demos.
4. Plot and test
libpopulation functions generate exploratory figures with attached statistical summaries.
5. Analyze timecourses
libtimeseries computes, saves, loads, filters, and combines PSTHs across units or sessions.
6. Move into state space
libss converts PSTH-derived arrays into state-space representations for dimensionality reduction and trajectory analysis.

Data Conventions

  • The central identifier for aggregated data is unitname, typically a five-part numeric key like subject, session, run, electrode, unit.
  • libbigtable assumes the first column of result files is the unit key and that later duplicate rows override earlier ones.
  • Missing values are represented as NaN.
  • The central time-series contract is the psth struct, with fields such as x, mean, sem, event, rate_rsp, and ginfo.

Strengths

  • Very practical end-to-end workflow for lab data analysis.
  • Strong separation between per-session saving, population loading, and downstream visualization.
  • Demos make the intended usage much clearer than in many MATLAB toolboxes.
  • Time-series support is broad and appears to be the most feature-rich part of the repo.
  • Utility layer is extensive, which keeps higher-level analysis scripts compact.

Tradeoffs And Risks

  • Heavy convention dependence: callers must follow expected naming and file formats.
  • Path-based toolbox usage means reproducibility depends on correct path setup.
  • Optional external dependencies are not bundled.
  • MATLAB script-style patterns and workspace assumptions are still present in some demos.
  • The toolbox is broad, so discoverability depends on knowing the right module and naming conventions.

Conclusion

libkm is best understood as a shared lab toolbox for behavioral and neural data analysis with a strong emphasis on practical workflows. It connects single-session outputs to population analysis and PSTH/state-space methods in a way that is optimized for iterative exploratory science rather than formal packaging.
